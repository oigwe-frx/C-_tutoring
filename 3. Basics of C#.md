# Intro to C#

Learning C# is a great language choice for new and experienced programmers.

What can we do with C#? We have a lot of options:
- Interactive websites
- Mobile apps
- Video games
- Desktop applications

C# is similar to Java, another programming language. Both are strongly typed and object oriented.


## Print

Copy and then paste this code into your Visual Studio Code .cs file
```
using System;

namespace HelloWorld
{
  class Program
  {
    static void Main()
    {
      Console.WriteLine("Hello World!");    
     }
  }
}
```
Run the code to see what happens: type ```dotnet run``` into your terminal, press return/enter


```Console.WriteLine("Hello World!");```

**Console.WriteLine()** is a command that prints text to a console. Whatever is in the parentheses will be printed to the console. In this case it’s Hello World!.

## Input

The command ```Console.ReadLine()``` captures text that a user types into the console/terminal. 

Copy and then paste this code into your Visual Studio Code .cs file

```
using System;

namespace GettingInput
{
  class Program
  {
    static void Main()
    {
      Console.WriteLine("How old are you?");
      string input = Console.ReadLine();
      Console.WriteLine($"You are {input} years old!");
    }
  }
}
```

### What is happening
1. Console.WriteLine("How old are you?"); **the program writes (print) a question to the console/terminal**
2. string input = Console.ReadLine();  **what the user types (aka the input) is stored in memory with the label ```input```**
3. Console.WriteLine($"You are {input} years old!"); **the program uses the stored input to print a sentence to the console**

## Comments

Not everything in a program needs to be computer instructions, you might also want to write a message to yourself or other programmers.

Text written in a program but not run by the computer is called a comment. In C#, anything after a ``//`` or between ``/*`` and ``*/`` is a comment.

Comments can:

- Provide context for why something is written the way it is:
```// This variable will be used to count the number of times the word travel is used in a document
int travelCount = 0; 
```

- Help other people to understand the code quickly:
```
/* Calculates tomorrow's rain likelihood 
as a number between 0 and 100 */ 

ComplicatedRainCalculationForTomorrow();
```


- Ignore a line of code and see how a program will run without it:
```
// string usefulValue = OldSloppyCode(); 
string usefulValue = NewCleanCode();
```

Developers tend to use "//" for short, one-line comments and "/* */" for anything longer.
