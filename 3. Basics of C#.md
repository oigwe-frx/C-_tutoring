## Print

Copy and then paste this code into your Visual Studio Code .cs file
```
using System;

namespace HelloWorld
{
  class Program
  {
    static void Main()
    {
      Console.WriteLine("Hello World!");    
     }
  }
}
```
 Run the code to see what happens: type ```dotnet run``` into your terminal, press return/enter


```Console.WriteLine("Hello World!");```

**Console.WriteLine()** is a command that prints text to a console. Whatever is in the parentheses will be printed to the console. In this case it’s Hello World!.

## Input

The command ```Console.ReadLine()``` captures text that a user types into the console/terminal. 

```using System;

Copy and then paste this code into your Visual Studio Code .cs file

namespace GettingInput
{
  class Program
  {
    static void Main()
    {
      Console.WriteLine("How old are you?");
      string input = Console.ReadLine();
      Console.WriteLine($"You are {input} years old!");
    }
  }
}
```

### What is happening
1. Console.WriteLine("How old are you?"); **the program writes (print) a question to the console/terminal**
2. string input = Console.ReadLine();  **what the user types (aka the input) is stored in memory with the label ```input```**
3. Console.WriteLine($"You are {input} years old!"); **the program uses the stored input to print a sentence to the console**
