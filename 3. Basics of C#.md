# Intro to C#

Learning C# is a great language choice for new and experienced programmers.

What can we do with C#? We have a lot of options:
- Interactive websites
- Mobile apps
- Video games
- Desktop applications
]
C# is similar to Java, another programming language. Both are strongly typed and object-oriented.


## Print

Copy and then paste this code into your Visual Studio Code .cs file
```
using System;

namespace HelloWorld
{
  class Program
  {
    static void Main()
    {
      Console.WriteLine("Hello World!");    
     }
  }
}
```

```Console.WriteLine("Hello World!");```

**Console.WriteLine()** is a command that prints text to a console. Whatever is in the parentheses will be printed to the console. In this case it’s Hello World!.

### Activity: Change the code in the editor so that your own name is printed to the console!
