# Setting Up the C# Environment

This lesson is for setting up a C# environment using VS Code and Visual Studio. 

- Introduce Visual Studio Code (VS Code) and Visual Studio IDE as tools for C# development.
- Learn the steps for installing the .NET SDK and configuring the VS Code workspace.
- Cover customization of the VS Code interface, including custom snippets.
- Demonstrate the installation of Visual Studio IDE and provide an overview of its features.

## Install VS Code

Install VS Code via <https://code.visualstudio.com/download?_exp_download=d53503e735>

## Install .NET SDK

Install .NET SDK via <https://dotnet.microsoft.com/en-us/download>
