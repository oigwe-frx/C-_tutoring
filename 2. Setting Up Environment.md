# Setting Up the C# Environment

This lesson is for setting up a C# environment using VS Code and Visual Studio. 

- Introduce Visual Studio Code (VS Code) and Visual Studio IDE as tools for C# development.
- Learn the steps for installing the .NET SDK and configuring the VS Code workspace.
- Cover customization of the VS Code interface, including custom snippets.
- Demonstrate the installation of Visual Studio IDE and provide an overview of its features.

## Install VS Code

Visual Studio Code (commonly referred to as VS Code) is an integrated development environment developed by Microsoft for Windows, Linux, macOS and web browsers. Features include support for debugging, syntax highlighting, intelligent code completion, snippets, code refactoring, and embedded version control with Git.

Install VS Code via <https://code.visualstudio.com/download?_exp_download=d53503e735>

## Install .NET SDK

The .NET SDK (often written as dotnet SDK) is a set of software tools and libraries used to build applications for C#, F#, and Visual Basic. 

1. Close VS Code
2. Install .NET SDK via <https://dotnet.microsoft.com/en-us/download>
   - download the version w/ active "Support Phase"
  
## VS Code Configuration and Templates

How To:
- Configure our workspace to use the downloaded .NET SDK.
- Create a new console app project using the terminal.
   - Top Menu Bar > Terminal > New Terminal
![Create A New VS Code Terminal Step 1](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_new_terminal.png)
   - Terminal appears in horizontal pane at the bottom
![Terminal Pane Appears](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_blank_terminal.png)
   - Create an example C# console app project
   - In your terminal type:
         - ```cd [folder name]``` instructs your computer to change/move to the file folder that you want to save your new project in
         - ```dotnet new console -n [project name]``` instructs your computer to create a new C# project with your chosen project name. The project name after -n can be any name that you want.
            - ex: ```dotnet new console -n HelloWorld```
     - press enter/return key on keyboard
![Terminal Commands To Create New Project](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_terminal_command_example_console_app.png)


- Open the created project folder and explore its contents, including the base template files.
   - Top Menu Bar > View > Explorer
![Open the explorer pane](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_open_explorer.png)
   - A left (Explorer) pane will open in your Visual Studio Code Window
![Opened explorer pane](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_open_explorer_2.png)
   - In the explorer pane, click on the **Open Folder** button
   - A finder box will appear on your screen. Once the finder box has appeared, navigate to the location in your file system that holds the project folder that you created. Once the folder is found, click on the icon to highlight the icon. Then click on the **Open** or **Select Folder** button 
![Opened explorer pane](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_open_explorer_3.png)
   - Your Visual Studio Explorer will now show the chosen folder and its contents
![Opened explorer pane](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_open_explorer_4.png)
   - In your explorer pane you will see all of the base templates files that you will need to begin your new project
      - Two critical files are:
         - the CS Project File : that will be used by dotnet to build the project [it is the file with the extension **.csproj**]
![Opened explorer pane](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_open_explorer_5.png)
         - the initial program file that where you will start writing your CS# code
![Opened explorer pane](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_open_explorer_6.png)

 
- Verify the target framework in the project file to ensure it points to the correct .NET SDK version.
   - In the explorer pane  click on the CS Project File [it is the file with the extension **.csproj**]
![Opened explorer pane](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/vs_open_explorer_5.png)
   - You can see which version of dotnet your project is using by looking at the ```<TargetFramework>``` component
![CS Project File](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/cs_proj_1.png)
   - In order to see what versions of dotnet are available on your system
      - Open your terminal and run the following command:
         - ```dotnet --list-sdks ```
![CS Project File](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/cs_proj_sdks.png)
        - the sdks version will be listed in the terminal, and will follow the pattern:
           - [version number] [file location on your computer]
           - ex: ```6.0.424 [C: Program Files\dotnet\sdk] ```

- Change the .NET SDK version by modifying the target framework if needed.
   - If you want to change the SDK version that your project is running:
      - Open the ,csproj file from your explorer (left) pane > code will appear in middle pane > find the  ```<TargetFramework>``` component >  you should see text that has the pattern ```net[version number]``` > directly change the number so that is is the same number of the sdks version that you want to use > save the change
     - SDK version before change:
![CS Project File](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/cs_proj_1.png)
     - SDK version after change:
![CS Project File](https://github.com/oigwe-frx/C-_tutoring/blob/main/photos/cs_proj_2.png)
